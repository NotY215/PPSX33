# PPSX33 Support

For usage questions and reproducible bugs, open an issue in the [PS3 repository](https://github.com/NotY215/PPSX33) and include:

- Operating system and compiler/toolchain versions.
- The command or steps used and the expected versus actual result.
- Relevant logs and a minimal reproduction where possible.
- The commit or release you are using.

Do not upload game dumps, decrypted ELFs, EBOOT files, encryption keys, or copyrighted assets. Use only games and files you own and are authorized to use.

This project is experimental. Commercial game compatibility, SPU emulation, RSX rendering, and broad system-library support are not currently guaranteed. See [README.md](README.md) and [ROADMAP.md](ROADMAP.md) for current status.
