# PPSX33 Security Policy

## Scope

Security reports may include memory-safety bugs, unsafe parsing of ELF input, path-handling vulnerabilities, unsafe compiler invocation, or runtime defects that could execute unintended host behavior.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option in the repository's Security tab when it is available. If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile and request a private reporting channel. Do not publish exploit details before a fix or mitigation can be coordinated.

Include the affected commit or version, host OS, impact, minimal reproduction steps, and relevant logs. Remove sensitive local paths and tokens. Do not attach copyrighted game files, decrypted game dumps, encryption keys, or materials you are not authorized to share.

## Response

The maintainer will review reports as time permits and may request additional information. This is a small project, so no fixed response-time guarantee is made.
