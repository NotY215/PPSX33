# Security Policy

## Scope

Security reports may include memory-safety bugs, unsafe parsing of ELF input, arbitrary code execution caused by the recompiler, path-handling vulnerabilities, or other security-relevant defects in this repository.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option in the repository's Security tab when it is available. If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile and request a private reporting channel. Do not publish exploit details before a fix or mitigation can be coordinated.

Include the affected commit or version, impact, reproduction steps, and any relevant logs. Do not attach copyrighted game files, decrypted game dumps, keys, or other materials you are not authorized to share.

## Response

The maintainer will review reports as time permits and may request additional information. This is a small project, so no fixed response-time guarantee is made.
