# PPSX33 Security Policy

## Scope

Security issues include memory-safety defects, unsafe ELF parsing, path-handling vulnerabilities, unsafe compiler invocation, and runtime defects that may cause unintended host behavior.

## Reporting

Use GitHub's **Report a vulnerability** option in the repository Security tab when available. If private vulnerability reporting is unavailable, contact the repository owner through the GitHub profile and request a private reporting channel. Avoid publishing exploit details before a fix or mitigation can be coordinated.

Include the affected commit or version, host OS, impact, minimal reproduction steps, and relevant logs. Remove tokens, personal data, and sensitive local paths. Do not attach game dumps, decrypted ELFs, encryption keys, EBOOT files, or materials that are not authorized for sharing.

## Response

Reports are reviewed as maintainer availability permits. No fixed response-time guarantee is provided for this project.
